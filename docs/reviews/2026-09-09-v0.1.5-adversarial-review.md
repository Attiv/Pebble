# v0.1.5 adversarial release review

Scope: all changes from v0.1.4 through d207969, with a second review of the release fixes. Three independent code reviews covered mail identity/dispatch, storage/migrations/backup, and synchronization/contact interactions. The primary review also covered settings UI, release version consistency and the publication workflow.

| Finding | Reproduction / consequence | Resolution |
| --- | --- | --- |
| P2: vCard unfolding removed real whitespace | A 75-byte folded line followed by content whitespace lost the separator on import | Remove exactly one continuation byte; Store export/import regression covers spaces and Tab |
| P2: vCard export allowed CR to become a property | A note containing CR followed by EMAIL added an unintended email when re-imported | Normalize CRLF/CR before TEXT escaping; regression asserts one original address |
| P2: SMTP retry did not check changed mailbox address | A queued From A could be dispatched through an account changed to B | Compare stored and current mailbox for every provider before dispatch; test asserts zero calls; rename-only retains the snapshot |
| P2: OAuth remote draft skipped identity verification | Restored metadata A with credentials B could upload a draft to B | Reuse the verified provider and sender from one preparation; verification failure preserves local draft and makes no remote call |
| P2: participant cache mapped the wrong address | Editing Alice's address to Bob while creating a contact made Alice open Bob | Cache only actual saved addresses and clear the removed original association |
| P2: Tab removed the recent-suggestion deletion control | Menu unmounted before native Tab could focus its button | Keep the menu until focus leaves; also prevent option mousedown from blurring input before click |
| P2: restore UI claimed skipped OAuth credentials were restored | Private restore preserved existing connections but success message claimed token replacement | Correct actual UI fallback and both translations; test the displayed restore result |

All seven findings were fixed. Follow-up review caught and fixed one pointer-focus regression during the keyboard change. No remaining actionable P1/P2 findings were identified in the reviewed scope; this is not a guarantee of defect-free software.

Validation on the final candidate:

- Rust workspace/all-target tests: 664 passed, 2 existing ignored.
- Frontend: 448 passed across 101 files.
- TypeScript/Vite production build passed (existing chunk-size advisory).
- Rust formatting and Clippy with warnings denied are recorded in the PR checks.
- Behavioral regressions reproduced the old vCard data changes, SMTP dispatch after an address edit, missing verified draft sender, wrong contact mapping, unreachable keyboard removal, incorrect restore text and pointer-focus regression before fixes.

Release process: merge the reviewed candidate after three-platform CI, tag the exact merged commit as v0.1.5, let the existing release workflow build Windows, Linux and both macOS architectures, verify the complete artifact set plus SHA-256 checksums, and publish only after every platform succeeds. Existing releases must not be overwritten.

Limits: no real provider credentials/controlled recipients were supplied, so live delivery and provider rewriting were not tested. Client wire/header and state-machine behavior is covered by automated tests. Outlook remains provider-managed; aliases and delegated sending are not enabled. The changelog states this limitation and asks users to verify sender names before formal use. Database migration/rollback is tested on synthetic fixtures; personal profiles and cross-platform GUI installation are not manually exercised.
